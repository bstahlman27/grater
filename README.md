# Grater

Grater is a game journal for tracking what you play, what you want to play, and what your friends think is worth your time. Search for games, save them to lists, write reviews, compare installed libraries, and let the game picker choose what to play next.

## Features

- Supabase email auth with user profiles, profile pictures, bios, and friend pages
- Game search backed by the RAWG API
- Personal game library, play later list, and installed list
- Per-list visibility controls for private or friend-visible games
- Installed platform tags for PC, Xbox, Nintendo, and PlayStation
- Reviews with half-star ratings, pinning, editing, deleting, likes, dislikes, and comments
- Timeline showing your reviews and friend-visible reviews from friends
- Friend requests, friend profile links, and friend-visible lists/reviews
- Solo and group game picker with multi-platform filtering
- Light and dark mode

## Tech Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Prisma 7
- Supabase Auth
- Postgres
- RAWG API
